🌐 AI Language Translator

«Intelligent • Fast • Simple • Multilingual»

A modern multilingual translation web app built with Python and Streamlit. It provides smart language detection, multiple translation engines, translation history, language swapping, download support, and a beautiful responsive interface.

✨ Features

- 🌍 23 Supported Languages
- 🔎 Smart Language Detection
- 🔄 Language Swap
- 🤖 Multiple Translation Engines
- 🕘 Translation History
- 📥 Download Translation
- 📊 Word & Character Statistics
- ☀️ Light & Dark Mode
- 📱 Responsive UI
- 🎨 Modern Animated Interface

🛠️ Built With

- 🐍 Python
- 🎈 Streamlit
- 🌐 Google Translator
- 🔤 "langdetect"
- 🔗 "deep-translator"
- 📡 "requests"
- 🎨 HTML & CSS

🌍 Supported Languages

English • Urdu • Pashto • Hindi • Arabic • Persian • French • Spanish • German • Italian • Portuguese • Russian • Japanese • Korean • Chinese • Turkish • Dutch • Gujarati • Marathi • Tamil • Bengali • Punjabi

⚙️ Installation

git clone [https://github.com/Hammad-PeerSb/AI--Language-Translator-PeerSb.git]
cd AI-Language-Translator

Create and activate a virtual environment:

python -m venv .venv
.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

▶️ Run Locally

streamlit run app.py

☁️ Deployment

The application can be deployed easily using Streamlit Community Cloud by connecting the GitHub repository and selecting:

Branch: main
Main file: app.py
